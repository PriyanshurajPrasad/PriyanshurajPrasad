## 🚀 Featured Projects

### 🧠 AI Study Buddy | MERN Stack

AI-powered full-stack learning platform enabling users to upload study materials, generate AI-based quizzes (10–15 questions per session), and receive detailed explanations for self-paced learning. Built with JWT authentication and MongoDB Atlas, deployed on Render + Vercel with sub-3-second API response times.

### 🩺 PhysioCare | MERN Stack

Full-stack physiotherapy appointment system supporting an end-to-end booking flow across multiple modules — user registration, login, appointment scheduling, and profile management. Implements JWT authentication and bcrypt password encryption, with RESTful APIs handling complete appointment CRUD operations. Architected for scale, with planned support for video consultations and real-time patient-doctor messaging.
